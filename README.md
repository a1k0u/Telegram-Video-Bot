# Telegram Video Bot — personal fork

:warning: This repository is an **independent fork** of [bohd4nx/Telegram-Video-Bot](https://github.com/bohd4nx/Telegram-Video-Bot).

I maintain changes here that are personally relevant to my own use cases.  
Some of these customizations are intentionally local in scope, so I am not particularly interested in contributing them to the upstream repository (_mostly they fastly vibe coded_).

## Differences from the upstream repository

- Sending the processed video note to a Telegram channel via a callback button.
- User whitelist support.
- Security audit through event logging.
